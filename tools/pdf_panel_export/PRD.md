# PDF 영역 자르기 → PNG 내보내기 도구 (PDF Crop Exporter)

## 1. 개요
PDF 파일을 불러와 사용자가 지정한 영역을 페이지마다 잘라내어, 1920x1080px 크기의 PNG 이미지로 저장하는 Windows 데스크톱 프로그램.

## 2. 목표 / 배경
- 스토리보드, 발표자료 PDF 등에서 특정 영역(예: 그림 프레임)만 추출해 균일한 해상도(1920x1080)의 이미지 시퀀스로 만들고 싶음.
- 반복 작업(페이지마다 같은 위치를 수동으로 캡처/크롭)을 자동화.

## 3. 사용자 / 사용 시나리오
- 대상 사용자: 본인(단독 사용), Windows PC.
- 시나리오: PDF를 열고 → 미리보기에서 자를 영역을 드래그로 지정(또는 좌표 직접 입력) → "내보내기" 클릭 → 모든 페이지에서 같은 영역을 잘라 PNG로 일괄 저장.

## 4. 범위 (Scope)

### 4.1 In Scope (MVP)
1. **PDF 열기**: 파일 선택 다이얼로그로 PDF 로드, 첫 페이지 미리보기 표시.
2. **영역 지정**
   - 마우스 드래그로 자를 영역을 사각형으로 지정.
   - 드래그 시작 시점부터 항상 16:9 비율로 고정(자유 비율 불가).
   - 드래그로 잡은 영역을 좌표 입력창(x, y, width, height 또는 x, y, scale)으로 미세 조정 가능.
   - 지정한 영역은 미리보기 위에 오버레이로 표시.
3. **일괄 크롭 & 내보내기**
   - 지정한 영역(16:9)을 모든 페이지에 동일하게 적용.
   - 각 페이지를 지정 영역만큼 잘라 1920x1080px로 렌더링 후 PNG로 저장.
   - 비율이 이미 16:9로 고정되므로 별도 레터박스/스트레치 처리 불필요 (단순 스케일).
   - 출력 파일명: `{PDF파일명}_page_001.png`, `_page_002.png` … (자릿수는 총 페이지 수에 맞춰 자동 결정).
   - 저장 폴더 선택 가능(기본값: PDF와 같은 폴더 하위에 `{PDF파일명}_export` 폴더 자동 생성).
4. **진행 상태 표시**: 페이지 수가 많을 경우 진행률 표시(예: "3/20 페이지 처리 중").
5. **에러 처리**: 손상된 PDF, 저장 권한 없음 등 기본적인 오류 메시지 표시.

### 4.2 Out of Scope (MVP 제외, 추후 검토)
- 페이지별로 다른 크롭 영역 지정 (이번 요청은 "모든 페이지 동일 영역"으로 확정됨).
- PDF 편집/주석 기능.
- macOS/Linux 지원.
- 클라우드 저장, 자동 업데이트.
- 다국어 UI (한국어만 지원).

## 5. 기능 요구사항 상세

| ID | 기능 | 설명 |
|----|------|------|
| F1 | PDF 로드 | PyMuPDF(fitz)로 PDF를 열고 페이지 이미지를 렌더링해 미리보기에 표시 |
| F2 | 드래그 선택 | Qt Graphics View 위에서 마우스 드래그로 사각형 생성, 16:9 비율 강제(가로 드래그 시 세로 자동 계산) |
| F3 | 좌표 직접 입력 | x, y, width(또는 scale) 입력 필드 제공, 입력 시 오버레이 즉시 갱신 |
| F4 | 영역 미리보기 | 선택 영역을 반투명 사각형으로 오버레이, 실시간 갱신 |
| F5 | 일괄 내보내기 | 전체 페이지 순회하며 지정 영역을 1920x1080px로 렌더링 후 PNG 저장 |
| F6 | 출력 경로 설정 | 저장 폴더 선택 UI, 기본 경로 자동 제안 |
| F7 | 진행률/완료 알림 | 처리 중 progress bar, 완료 시 알림 및 출력 폴더 열기 버튼 |

## 6. 비기능 요구사항
- **성능**: 100페이지 PDF 기준 1~2분 이내 처리 목표 (PDF 해상도에 따라 변동 가능).
- **해상도 처리**: PDF는 벡터 기반이므로, 자른 영역을 목표 1920x1080에 맞는 DPI로 직접 렌더링(저해상도 렌더 후 확대 방식 지양 → 화질 저하 방지).
- **플랫폼**: Windows 10/11.
- **배포 형태**: PyInstaller로 단일 실행 파일(.exe)로 패키징, 설치 없이 실행 가능.

## 7. 기술 스택
- 언어: Python 3.11+
- GUI: PySide6 (Qt for Python)
- PDF 렌더링: PyMuPDF (fitz)
- 이미지 처리: Pillow (필요 시 후처리)
- 패키징: PyInstaller → 단일 exe

## 9. 성공 기준 (Acceptance Criteria)
- 임의의 PDF를 열고 드래그로 영역을 지정하면 16:9 비율이 항상 유지된다.
- 좌표 입력으로 영역을 미세 조정할 수 있고, 미리보기에 즉시 반영된다.
- "내보내기"를 누르면 모든 페이지에서 동일 위치의 영역이 1920x1080px PNG로 저장된다.
- 출력 이미지가 실제 PDF 내용과 위치/비율이 일치한다(왜곡 없음).
- 100페이지 내외의 PDF에서도 프로그램이 멈추거나 크래시하지 않는다.

## 10. 향후 확장 아이디어 (Backlog)

- JPEG 등 다른 출력 포맷 지원
- 배치로 여러 PDF 동시 처리
- 크롭 영역 프리셋 저장/불러오기

## 11. 리스크 / 확인 필요 사항
- PDF마다 페이지 크기(용지 사이즈)가 다를 경우, 동일 좌표가 페이지마다 다른 위치를 가리킬 수 있음 → 기본적으로 "첫 페이지 기준 절대 좌표"를 모든 페이지에 동일 적용(페이지 크기가 다르면 좌표가 페이지 밖으로 나갈 수 있다는 점을 사용자에게 안내).
